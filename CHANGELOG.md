# [1.1.0] - 2026-09-24

## Release Name

Hybrid Knowledge Platform Edition

---

## Overview

Version 1.1 represents the completion of the core OKF-IngestRAG platform architecture.

This release introduces:

- Knowledge governance
- Service awareness
- Relationship mapping
- Knowledge recommendations
- Context assembly
- Dashboarding
- Hybrid retrieval foundations
- Explainable RAG architecture

The platform now supports the complete journey from knowledge ingestion to AI-ready context generation.
