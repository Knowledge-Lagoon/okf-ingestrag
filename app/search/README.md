# Search Module

## Purpose

The Search Module provides keyword and metadata-based knowledge discovery.

---

## Search Types

### Keyword Search

```text
Document Content
Titles
Descriptions
```

### Metadata Search

```text
Tags
Types
Owners
Sources
```

---

## Data Flow

```text
Question
    ↓
Search Engine
    ↓
Matching Documents
```

---

## Output

Search returns candidate knowledge documents for further retrieval and ranking.

---

## Consumers

- Retrieval Layer
- Assistant
- Hybrid Retrieval
