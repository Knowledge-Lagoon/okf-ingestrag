# Retrieval Module

## Purpose

The Retrieval Module loads document content after search results are identified.

---

## Responsibilities

- Retrieve search results
- Load supporting content
- Return structured document data

---

## Data Flow

```text
Question
    ↓
Search
    ↓
Retrieval
    ↓
Documents
```

---

## Output

Retrieved documents are consumed by:

- Context Builder
- Recommendations
- Assistant
- Hybrid Retrieval

---

## Summary

Retrieval provides access to the content behind search results.
